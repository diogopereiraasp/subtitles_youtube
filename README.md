# YouTube Subtitle Sidebar Browser Extension

A Chrome Manifest V3 browser extension that captures YouTube video subtitles and displays the complete interactive transcript on the right side of the YouTube watch page.

## Features
- 📜 **Complete Video Subtitles**: Displays all captions from 0:00 to the end of the video.
- 🎯 **Click-to-Seek**: Click any timestamp or line to jump the video to that exact point.
- ⚡ **Synchronized Auto-Scroll**: Highlights current line and smooth-scrolls with video playback.
- 🌐 **Multi-Language Support**: Choose between available manual and auto-generated subtitle tracks.
- 🔍 **Live Search**: Filter the entire transcript in real time.
- 📋 **Copy Full Transcript**: Copy formatted text with timestamps in one click.

## How to Install in Chrome / Brave / Edge

1. Open `chrome://extensions` (or `brave://extensions` / `edge://extensions`).
2. Turn ON **Developer mode** (top right toggle).
3. Click **Load unpacked**.
4. Select the project folder:
   `/Users/diogopereira/Desktop/custom-subtitles`
5. Visit any YouTube video watch page to see your subtitle sidebar on the right!
